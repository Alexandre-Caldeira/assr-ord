ORDs usadas em ASSR (Lista e Explicações):

Magnitude Squared Coherence (MSC):

Princípio: Mede a linearidade e a consistência de fase da resposta EEG em relação a si mesma através de diferentes épocas/segmentos na frequência de interesse. Valores altos indicam uma resposta consistente e sincronizada com o estímulo (indiretamente).

Fórmula (para um canal/frequência):
MSC(f) = | Σ_i X_i(f) |^2 / (M * Σ_i |X_i(f)|^2)
onde X_i(f) é o valor da FFT na frequência f para a i-ésima época, e M é o número de épocas.

pMSC (Productory MSC - pMSC.m): Combina MSCs de múltiplos canais (N) multiplicando-as e tomando a N-ésima raiz.
pMSC(f) = [Π_c MSC_c(f)]^(1/N) (onde c é o índice do canal)

Component Synchrony Measure (CSM) / Magnitude Squared Coherence of an average (MCSC) / Phase Synchrony Index (PSI):

Princípio: Mede a consistência de fase através das épocas na frequência de interesse, ignorando a magnitude. Um valor alto indica que a fase da resposta é consistente entre as épocas.

Fórmula (para um canal/frequência, como em MCSM.m e rlord_gen_states):
CSM(f) = ( (1/M) * Σ_i cos(θ_i(f)) )^2 + ( (1/M) * Σ_i sin(θ_i(f)) )^2
onde θ_i(f) é a fase da FFT na frequência f para a i-ésima época.

Multi-channel CSM (MCSC): Pode ser a média ou outra combinação de CSMs por canal.

F-Test (Estatística F):

Princípio (Clássico): Compara a variância de duas amostras. No contexto espectral, compara a potência na frequência do sinal com a potência média nas frequências vizinhas (ruído). Um valor F alto sugere que a potência do sinal é significativamente maior que o ruído.

Fórmula (Local Spectral F-test para um canal):
F(f_0) = Potência(f_0) / Média(Potência(f_vizinhas))
onde Potência(f) é |X(f)|^2. Graus de liberdade são tipicamente (2, 2L) onde L é o número de bins vizinhos.

aLFT (Additive LFT - aLFT_FP.m e aLFT.m): Soma (ou média) os valores F de cada canal. FyN = mean((Yfo.^2)./(1/L*sum(Yfn.^2,1)))

pLFT (Productory LFT - pLFT_FP.m e pLFT.m): Multiplica os valores F de cada canal e toma a N-ésima raiz. FyN = (prod((Yfo.^2)./(1/L*sum(Yfn.^2,1)))).^(1/N)
Nota: Os arquivos pLFT_FP.m e pLFT.m têm lógicas ligeiramente diferentes para selecionar as frequências vizinhas (Yfn). pLFT_FP usa um conjunto fixo de vizinhos, enquanto pLFT usa uma banda contígua.

Global Beta Test (GBT) / Teste Beta:

Princípio: Compara a potência do sinal+ruído com a potência apenas do ruído (obtido de um segmento de referência ou de um sinal de ruído separado). Baseado na distribuição Beta.

Fórmula (para um canal/frequência):
β(f) = S_vv(f) / (S_vv(f) + S_nn(f))
onde S_vv(f) é a potência espectral do sinal+ruído e S_nn(f) é a potência espectral do ruído de referência, ambas na frequência f.

aGBT (Additive GBT - aGBT.m): Média dos Betas de cada canal. abeta = mean(Svv./(Svv+Snm),3)

pGBT (Productory GBT - pGBT.m): Produto dos Betas de cada canal, elevado a 1/N. pbeta = (prod(Svv./(Svv+Snm),3)).^(1/N)

MGBT (Multivariate GBT - MGBT.m do anexo inicial): Combinação multivariada que usa a soma das potências através dos canais antes de formar a razão. betaN = Svv_total_N_canais / (Svv_total_N_canais + Snm_total_N_canais)

Correlação:

Princípio: Mede a relação linear entre duas variáveis. No contexto ASSR, pode ser usado para correlacionar a forma de onda da resposta média com um template senoidal, ou a correlação entre respostas em diferentes canais.

Fórmula (Pearson): r = Σ[(x_i - mean(x))(y_i - mean(y))] / sqrt(Σ(x_i - mean(x))^2 * Σ(y_i - mean(y))^2)

Mutual Information (MI):

Princípio: Mede a quantidade de informação que uma variável aleatória contém sobre outra. Pode ser usada para medir a dependência estatística entre o estímulo e a resposta EEG, ou entre diferentes características da resposta. Mais geral que correlação, pois captura relações não lineares.

Fórmula (Discreta): I(X;Y) = Σ_y Σ_x p(x,y) log( p(x,y) / (p(x)p(y)) )
O cálculo prático requer discretização e estimativa das distribuições de probabilidade.

def msc_fft_py(Y_input, M_win):
    if Y_input.shape[1] == 0 or M_win == 0: return np.zeros(Y_input.shape[0])
    current_M_win = min(M_win, Y_input.shape[1])
    if current_M_win == 0: return np.zeros(Y_input.shape[0])
    if current_M_win == 1: return np.ones(Y_input.shape[0])
    Y_to_use = Y_input[:, :current_M_win]
    numerator = np.abs(np.sum(Y_to_use, axis=1))**2
    denominator = current_M_win * np.sum(np.abs(Y_to_use)**2, axis=1)
    msc = np.zeros_like(numerator, dtype=float)
    valid_den = denominator != 0
    msc[valid_den] = numerator[valid_den] / denominator[valid_den]
    msc[np.isnan(msc)] = 0; msc[np.isinf(msc)] = 0
    return msc

def wilson_score_interval_py(k, n, confidence_level=0.95):
    if n == 0: return np.nan, (np.nan, np.nan)
    alpha = 1 - confidence_level; z = norm.ppf(1 - alpha / 2)
    phat = k / n
    term1 = phat + (z**2) / (2 * n)
    term2 = z * np.sqrt((phat * (1 - phat) / n) + (z**2) / (4 * n**2))
    denominator = 1 + (z**2) / n
    pci_l = max(0, (term1 - term2) / denominator)
    pci_u = min(1, (term1 + term2) / denominator)
    return phat, (pci_l, pci_u)
